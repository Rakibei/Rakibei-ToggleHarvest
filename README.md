# Rakibei-ToggleHarvest

A small mod that changes mouse harvesting behavior by adding a toggle option.

## Features

* Click a harvest button once to start harvesting continuously.
* Click it again to stop harvesting.
* Switching to another harvest option automatically moves the toggle to that resource.
* Works alongside the existing hover-to-harvest option.
* When hover harvesting is enabled:

  * Hovering still starts harvesting normally.
  * Moving the mouse away stops harvesting.
  * Clicking while hovering locks harvesting on.
  * Moving the mouse away after clicking will continue harvesting until toggled off.

## Notes

This mod only changes mouse harvesting behavior and does not modify harvesting speed, resource values, or other gameplay mechanics.
